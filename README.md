# Dodge the Creeps

Un petit jeu réalisé avec **Godot 4**, dans lequel le joueur doit esquiver des ennemis et survivre le plus longtemps possible.

## But du jeu

Déplacez le joueur pour éviter les ennemis. Une collision met fin à la partie : essayez de survivre le plus longtemps possible !

## Commandes

- **Flèches directionnelles** : déplacer le joueur
- **Entrée** : lancer ou relancer une partie sans cliquer sur le bouton **Start**

## À propos du projet

Ce projet a été réalisé en suivant le [**tutoriel officiel de Godot 4**](https://docs.godotengine.org/fr/4.x/getting_started/first_2d_game/index.html#prerequisites). Je l’ai créé pour découvrir Godot et apprendre les bases du développement de jeux vidéo (*game dev*).
